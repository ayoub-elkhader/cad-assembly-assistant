# Example facts

| File | Source | Content |
|---|---|---|
| `pin_in_plate.json`, `shaft_stack.json`, `caged_cube.json` | synthetic assemblies of `exploded-view-verifier` (OCCT primitives) | geometry facts, no joints |
| `automate_d0582033.json` | computed from the AutoMate assembly `d0582033f0141c533610a96c_d40c2867992e69bbd192807e_08e55af239fdbe1add9c0078_default` with `facts_from_automate` | 8 parts, 14 annotated mates |

The synthetic facts are regenerated by `scripts/build_examples.py` (a test checks that they are up to date).

The AutoMate facts are derived from: B. Jones, D. Hildreth, D. Chen, I. Baran, V. G. Kim, A. Schulz, *AutoMate: A Dataset and Learning Approach for Automatic Mating of CAD Assemblies*, ACM TOG 40(6), 2021. Data: [doi:10.5281/zenodo.7750955](https://doi.org/10.5281/zenodo.7750955), CC0. The source files are in the `examples/automate/` folder of [cad-exploded-view-verifier](https://github.com/ayoub-elkhader/cad-exploded-view-verifier).
